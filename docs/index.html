01The idea

A model predicts the next token. A world model predicts what happens next — cheaply, and knows when it stopped being right.

A trained network already computes a rich internal state; what it lacks is a dynamics over that state you can run without paying for the network. sigmoid supplies one. It reads activations, compresses each window into a topological signature, fits a linear operator that advances the signature, and rolls the operator forward in place of the model.

The operator is a ridge solve — convex, closed-form, no gradients — so calibration is seconds and one imagined step is a single matrix–vector product.

State

Persistence barcode plus a decodable PCA channel, z = [ψ ; u].

Dynamics

Ridge-fit linear operator, optionally action-conditioned.

Self-check

A cohomological obstruction that fires without invoking the model.

02The pipeline

Expensive topology at calibration; a matvec and two norms at runtime.

03The mathematics

Three constructions, each doing one job.

H₀ without building a complex

For a Vietoris–Rips filtration the H₀ death times are the single-linkage merge heights — the edge weights of the Euclidean minimum spanning tree. So the barcode is exact and costs one MST, with no simplicial complex anywhere:

B₀(X) = { (0, w) : w ∈ MST(X) } ∪ { (0, ∞) }

That identity is also why the sparse-attention schedule runs 13× faster than the reference: merges only ever occur along MST edges, so n−1 edges carry the whole barcode where a naive implementation sorts n(n−1)/2 pairs.

A barcode as a vector

A barcode has no fixed length, so a linear operator cannot act on it. The numerator of its Hilbert series fixes that — bin births positive, deaths negative:

N(s) = Σᵢ s^bᵢ − Σᵢ s^dᵢ

Sanity check that holds in the test suite: N(1) equals the number of essential classes.

The coupling operator and its certificate

Fit T by ridge regression on paired states — convex, closed-form:

W = (XᵀX + λI)⁻¹ XᵀY

If the spectral norm ρ of the state block is below 1 the rollout is a contraction, and Banach gives a unique fixed point plus an a-priori error bound after n steps:

E(n) ≤ ε · (1 − ρⁿ) / (1 − ρ)

Contraction is reported, never forced. Clipping ρ below 1 buys a tidy certificate by misreporting the dynamics — on a chaotic system a positive Lyapunov exponent is expansion. Measured on Lorenz, clipping degraded one-step error from 0.067 to 0.317. So rho_max defaults to None, and the certificate reports whatever the data actually shows.

The gate, as a sheaf

An imagined state cannot be checked against truth — the truth is precisely what you declined to compute. So check it against itself. Put two stalks over each time index, ψ and u, learn the restriction map R : u → ψ where real data glues, and measure the obstruction:

r = ‖ R·û − ψ̂ ‖

Nothing in the least-squares fit forces an imagined ψ to remain the true signature of an imagined u, so r grows exactly when the rollout leaves the manifold — and it needs no forward pass to compute.

05When topology pays

Two clauses, both established by trying to break them.

Representation. The component count must have a plateau in radius — a band, fixed relative to the configuration's own scale, on which H₀ is constant. The plateau centre is the interaction radius; its width is how much error in stating that radius the encoder absorbs.

Prediction. That partition must be an input to the dynamics, not merely an observable of them.

Entity systems with contact radii satisfy both — what merges determines what moves. Token sequences satisfy the first and fail the second: ψ there encodes lexical repetition, a faithful tally of what already happened, which exerts no force on what happens next.

Scope, stated plainly

Representing topological structure works and is reproducible. Predicting with it does not yet: ψ contributes ≈0 to coordinate rollout, forecasting topology barely beats a persistence baseline, and the certificate stays vacuous on an LLM. Every one of those is measured, with the numbers in SIGMOID.md.

06Start

pip install -e .
import sigmoid

wm = sigmoid.wrap(model, prompts)     # calibrate on captured activations
r  = wm.imagine(wm.observe(window), steps=16)

r.hiddens          # predicted activations
r.grounded_at      # where it stopped trusting itself

For states that are a set of things — particles, bodies, agents — give the encoder the entity width and the interaction radius, then plan against it:

from sigmoid.control import TopologicalMPC, target_cost

config = sigmoid.SigmoidConfig(entity_dim=2, abs_radii=(0.9,))
mpc    = TopologicalMPC(world, action_low=-np.ones(8), action_high=np.ones(8))
plan   = mpc.plan(window, target_cost(world, goal))

plan.action        # execute this
plan.feasible      # False -> the model declines to guess
